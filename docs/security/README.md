# Documentação de segurança

O modelo de segurança existente permanece em [../security-model.md](../security-model.md); ele não foi movido para evitar quebrar links. Consulte também [ADR-0003 — OIDC com Keycloak](../decisions/0003-oidc-keycloak.md).

Este diretório é o ponto de entrada para futuras especificações especializadas de segurança. Não duplica o modelo existente. A configuração em código e as authorities efetivamente aplicadas continuam sendo a fonte para comportamento implementado; matrizes de módulos futuros são planejamento até existirem endpoints e testes correspondentes.
